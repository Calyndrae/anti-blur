It has no way to spy on you

Not a promise — a property of the code. The extension asks for no permission that would let it store, upload or remember anything. Here is the whole manifest.

Servers it can contact
None
Data written to disk
None
Analytics and ad code
None
Third-party libraries
None
Cost, accounts, upsells
None

manifest.json

{
  "manifest_version": 3,
  "name": "Anti Blur",
  "version": "1.0.0",

  // no "permissions" key at all
  // no background service worker
  // no host_permissions

  "content_scripts": [{
    "matches": ["<all_urls>"],
    "js": ["inject.js"],
    "run_at": "document_start",
    "world": "MAIN"
  }]
}

One script, about ninety lines. Short enough that you can read it yourself.
