Privacy Policy — Anti Blur

Chrome extension · Effective 29 August 2026 · Version 1.0.0

Anti Blur collects nothing. It has no servers, makes no network requests, stores no data, and contains no analytics, tracking or advertising code. Everything it does happens locally in your browser and is discarded the moment you close the tab.

What the extension does

Anti Blur runs a single script on the pages you visit. That script adjusts standard browser APIs so that a website cannot tell when you switch tabs, click into another window, or move your mouse off the page. Specifically it makes the page report itself as focused and visible, and it stops blur, visibilitychange and related events from reaching the website's own code.

This is a purely local modification of how a web page perceives your browser. No information about you, the page, or your activity leaves your device as a result.

Permissions and why they exist

  • Access to the websites you visit (<all_urls> content script). The extension's entire purpose is to change how a page perceives your focus, so its script has to run on the page itself. It runs on every site because focus and visibility detection can appear on any site. The script only reads and modifies browser APIs — it does not read page content, form fields, or anything you type.

Anti Blur requests no other permissions. It has no background service worker, no storage permission, no host permission for any remote server, and no ability to make network requests.

Data sharing and sale

Because no data is collected, none is shared, sold, rented, transferred, or disclosed to anyone — including us. There are no third-party services, SDKs, libraries or analytics providers of any kind in this extension. No data is used to determine creditworthiness or for lending purposes.

Remote code

The extension executes no remotely hosted code. All of its code is contained in the package the Hub loads into the browser, where it can be inspected.

Children

Anti Blur is not directed at children and, since it collects no data, it collects no data from children.

Changes to this policy

If a future version of Anti Blur ever handles data differently, this policy will be updated before that version ships, and the effective date above will change. Material changes will be noted in the Pioneering changelog.
